# CustomBDSP - clean tree

PC rebuild of Pokémon Brilliant Diamond (Switch v1.3.0, Unity 2019.4.27f1). This repository's code was produced
without any third-party reconstruction project:

- **Declarations** (`Assets/Scripts/{Game,AssetAssistant,DebugLog,nn,DOTweenPro}`) are generated by
  `tools/clean/skelgen` from our own Il2CppDumper dump of the game's metadata; attribute arguments are decoded from
  the game's own attribute generator functions (`tools/clean/attr_decode.py`).
- **Method bodies** are translated from the decompiled game binary (Ghidra + our cleaner), by this workspace's own
  restoration campaign, by a deterministic pass over exact instruction shapes, or by clean-room translators that work
  only from the binary.
- `Assets/Scripts/_Ours` holds this workspace's own platform layer (PC input, display, saves, keyboard, frame clock).
- `Assets/Scripts/_Skeleton` holds generator helpers that disappear when the last placeholder body is filled.

A body still reading `{ /*@B <token>*/ throw null; }` is a placeholder waiting for translation.
